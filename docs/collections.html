Collections, Maps & Sets

Ergonomic helpers over List, Map, Set, and Iterable, from lithej-collections. Every method takes and returns standard JDK collection types.

Lists

List<Integer> numbers = Lists.of(1, 2, 3, 4, 5, 6, 7, 8);   // immutable, like List.of
List<Integer> mutable = Lists.mutable(1, 2, 3);              // new ArrayList

Lists.map(numbers, n -> n * 2);
Lists.filter(numbers, n -> n % 2 == 0);
Lists.reject(numbers, n -> n % 2 == 0);                       // inverse of filter
Lists.find(numbers, n -> n > 5);                              // Optional<Integer>, first match
Lists.distinct(numbers);                                       // preserves first-occurrence order
Lists.flatten(List.of(List.of(1, 2), List.of(3, 4)));

Lists.chunk(numbers, 3);            // [[1,2,3],[4,5,6],[7,8]]
Lists.partition(numbers, n -> n > 4);   // Map<Boolean, List<Integer>>
Lists.zip(List.of("a","b"), List.of(1,2));  // pairs, truncated to the shorter list
Lists.groupBy(numbers, n -> n % 2 == 0 ? "even" : "odd");
Lists.countBy(numbers, n -> n % 2 == 0 ? "even" : "odd");      // Map<K, Long>

Lists.sortBy(numbers, Comparator.reverseOrder());               // new list, input untouched
Lists.minBy(numbers, Comparator.naturalOrder());
Lists.maxBy(numbers, Comparator.naturalOrder());

Lists.take(numbers, 3);
Lists.drop(numbers, 3);
Lists.first(numbers);
Lists.last(numbers);

Maps

Map<String, Integer> scores = Map.of("alice", 90, "bob", 75);

Maps.invert(scores);                          // throws IllegalStateException on duplicate values
Maps.filterKeys(scores, k -> k.startsWith("a"));
Maps.filterValues(scores, v -> v >= 80);
Maps.mapValues(scores, v -> v + 5);
Maps.merge(scoresA, scoresB, Integer::sum);    // scoresB wins ties unless the resolver says otherwise
Maps.groupBy(people, Person::department, Person::name);

Sets

Set<Integer> a = Sets.of(1, 2, 3);
Set<Integer> b = Sets.of(2, 3, 4);

Sets.union(a, b);          // {1,2,3,4}
Sets.intersection(a, b);   // {2,3}
Sets.difference(a, b);     // {1}  (in a, not in b)
Sets.isSubsetOf(a, b);     // false

Iterables

Iterables.toList(someIterable);
Iterables.size(someIterable);      // O(1) if already a Collection, else O(n)
Iterables.isEmpty(someIterable);
Iterables.firstOf(someIterable);   // Optional<T>
Null policy: the collection and function/predicate arguments are validated non-null (throwing NullPointerException) — a null collection is a bug, not treated as empty. Individual elements inside a collection may be null unless a method's Javadoc says otherwise.
