Installation

Add one dependency and start calling static methods — no installer, code generation, or framework bootstrapping.

These coordinates will work once the corresponding version is actually published to Maven Central or JitPack — see the project's CONTRIBUTING.md for the publishing setup.

Maven

Depend on just the module(s) you need:

<dependency>
    <groupId>io.github.mirfaizan06</groupId>
    <artifactId>lithej-core</artifactId>
    <version>1.0.0</version>
</dependency>

...or pull in every module with the aggregate artifact:

<dependency>
    <groupId>io.github.mirfaizan06</groupId>
    <artifactId>lithej</artifactId>
    <version>1.0.0</version>
</dependency>

Gradle (Kotlin DSL)

implementation("io.github.mirfaizan06:lithej-core:1.0.0")
// or
implementation("io.github.mirfaizan06:lithej:1.0.0")

Gradle (Groovy DSL)

implementation 'io.github.mirfaizan06:lithej-core:1.0.0'

JitPack (fallback)

If you'd rather not wait on a Maven Central publish, every tagged release is also installable via JitPack:

<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>
<dependency>
    <groupId>com.github.MirFaizan06</groupId>
    <artifactId>lithej</artifactId>
    <version>v1.0.0</version>
</dependency>
