API Reference

This site covers usage guides with copy-paste examples. For the complete generated Javadoc — every public class, method, parameter, return value, and exception — see the per-module Javadoc jars published with each release.

Generated Javadoc

Each module publishes a Javadoc jar alongside its regular and sources jars (attached to every GitHub Release, and to the corresponding Maven Central / JitPack artifact). Most IDEs (IntelliJ IDEA, Eclipse, VS Code with the Java extension) download and show this Javadoc automatically once you add the dependency — hover or invoke "Quick Documentation" on any LitheJ class or method.

To generate it locally from a clone of the repository:

./mvnw javadoc:javadoc -pl lithej-core
# output in lithej-core/target/site/apidocs/index.html
