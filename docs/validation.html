Validation

Argument checks that throw a standard JDK exception with a clear message and return the validated value, from lithej.core.Validate, so checks read naturally inline.

this.name = Validate.notBlank(name, "name");
this.age = Validate.range(age, 0, 150, "age");

Exception policy

Null checks throw NullPointerException; content/shape checks throw IllegalArgumentException — the same split the JDK itself uses (e.g. Objects.requireNonNull), so catch blocks keyed on exception type behave predictably.

Validate.notNull(value, "value");            // NPE if null
Validate.notBlank(text, "text");             // NPE if null, IAE if blank
Validate.notEmpty(list, "list");             // NPE if null, IAE if empty
Validate.notEmpty(map, "map");

Validate.isTrue(condition, "message");       // IAE if false

Validate.range(value, min, max, "name");     // inclusive, works for long and double
Validate.positive(value, "name");            // > 0
Validate.nonNegative(value, "name");         // >= 0

Validate.matches(value, pattern, "name");    // must match the Pattern entirely
Validate.isEmail(value);                     // boolean, syntax check only
isEmail is a syntax check only — it confirms the string has the basic shape local@domain.tld. It does not verify the mailbox exists, has valid DNS records, or can receive mail. Don't treat it as proof of deliverability.
