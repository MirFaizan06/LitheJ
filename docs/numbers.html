Numbers

Safe parsing, clamping, and rounding, from lithej.core.Numbers.

Parsing

Two families: parseX matches the JDK's own parseX (throws NumberFormatException), but trims whitespace first. tryX never throws, returning an empty OptionalX instead.

Numbers.parseInt(" 42 ");        // 42
Numbers.tryInt("not a number");  // OptionalInt.empty()
Numbers.tryInt("42");            // OptionalInt.of(42)
Numbers.tryLong(s);
Numbers.tryDouble(s);
Numbers.isInteger("42");         // true

Clamping & ranges

Numbers.clamp(15, 0, 10);      // 10
Numbers.clamp(-5, 0, 10);      // 0
Numbers.inRange(5, 0, 10);     // true

Rounding

Uses BigDecimal internally to avoid binary-floating-point surprises (e.g. 2.675 incorrectly rounding down to 2.67 under naive double math):

Numbers.round(2.675, 2);   // 2.68
Numbers.round(1.005, 2);   // 1.01
