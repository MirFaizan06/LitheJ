Text

String helpers for blank checks, splitting, joining, casing, padding, and substring extraction, from lithej.text.Text in lithej-core.

Text.isBlank(null);                        // true
Text.isBlank("   ");                       // true
Text.isNotBlank("hi");                     // true

Text.words("  hello   world  ");           // ["hello", "world"]
Text.lines("a\nb\r\nc");                   // ["a", "b", "c"]
Text.join(", ", List.of("a", "b", "c"));   // "a, b, c"
Text.repeat("ab", 3);                      // "ababab"
Text.reverse("hello");                     // "olleh"  (surrogate-pair safe)

Text.capitalize("hello");                  // "Hello"
Text.uncapitalize("Hello");                // "hello"
Text.titleCase("hello world");             // "Hello World"

Text.truncate("hello world", 5);           // "hello"
Text.ellipsis("hello world", 8);           // "hello..."
Text.padLeft("7", 3, '0');                 // "007"
Text.padRight("7", 3, '0');                // "700"

Text.removePrefix("prefixed-value", "prefixed-");  // "value"
Text.removeSuffix("value.txt", ".txt");            // "value"
Text.substringBefore("a=b=c", "=");                // "a"
Text.substringAfter("a=b=c", "=");                 // "b=c"
Text.between("<a>value</a>", "<a>", "</a>");  // Optional["value"]
Text.count("aaaa", "aa");                          // 2 (non-overlapping)
Unicode: methods operate on Unicode code points where that matters (e.g. capitalize title-cases the first code point, not just the first char, and reverse keeps surrogate pairs intact) but do not implement full grapheme-cluster segmentation (UAX #29) — a base character and a separate combining-mark code point can still be reordered by reverse. Use java.text.BreakIterator if you need grapheme-correct processing.
