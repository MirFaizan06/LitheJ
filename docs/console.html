Console

Validated, retrying prompts over stdin/stdout — or over any stream you inject for testing.

Console is a static facade over System.in/ System.out, convenient for scripts and small CLI tools. ConsoleIO is the same API bound to streams you construct, for code you want to unit test.

Basic output

Console.print("no newline");
Console.println("with a newline");
Console.println();
Console.printf("%s is %d%n", "age", 42);

Reading input

String name = Console.ask("Name: ");
int age = Console.askInt("Age: ");                 // retries until a valid int, no limit
int tries = Console.askInt("Age: ", 3);             // throws IllegalStateException after 3 bad tries
long id = Console.askLong("ID: ");
double price = Console.askDouble("Price: ");
boolean sure = Console.askBoolean("Continue? ");    // accepts y/yes/true, n/no/false (case-insensitive)
boolean ok = Console.confirm("Proceed?");           // same as askBoolean, with "(y/n): " appended
String pass = Console.readPassword("Password: ");   // masked if a real console is attached

Validated input

String email = Console.ask("Email: ", Validate::isEmail, "That doesn't look like an email.");

Menus

String color = Console.choose("Pick a color:", List.of("red", "green", "blue"));

Testing console interaction

Don't redirect System.in/System.out in tests — construct a ConsoleIO over your own streams instead, and depend on ConsoleIO (not Console) in code you want to test:

var in = new ByteArrayInputStream("42\n".getBytes(UTF_8));
var out = new ByteArrayOutputStream();
ConsoleIO console = new ConsoleIO(in, new PrintStream(out, true, UTF_8));

int age = console.askInt("Enter age: ");
assertEquals(42, age);
assertTrue(out.toString(UTF_8).contains("Enter age: "));
Thread safety: a ConsoleIO (and the shared Console instance) is not thread-safe for concurrent reads — a console session is inherently single-reader. Use one instance per session, from one thread.
